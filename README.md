# 出图台 · ComfyUI

本机 ComfyUI 的 Hana App。不要求你背提示词、不要求你拖节点——**看图挑风格**，然后在自己的机器上出图。

62 条中文风格配方开箱即用（随包 61 张样图），工作流固定在应用内部（Qwen-Image-2.1）。

---

## 它解决的问题

ComfyUI 本身很强，但门槛卡在两个地方：一是**节点图**，想调一个风格得先搭一串 loader、sampler、upscale；二是**提示词**，同一个效果要写成一句几十词的英文串，改一个字画面就变样。

出图台把这两件事拆开——节点图由应用自己拼，提示词由配方提供，你只做一件事：从样图里挑一个。

---

## 三条设计线

### 一、只传 id，不传提示词串

界面永远只告诉管线一个 `style id`，正向/负向串的**解算只发生在 `lib/styles.mjs` 这一处**。

这样做的原因很直接：如果界面也能拼字符串，同一个风格就会在不同入口长出不同结果，出了问题没法定位是谁写错了。现在配方是唯一权威，界面上看到的 `ink` 和管线收到的 `ink` 一定是同一份。

### 二、配方有状态，不许假装

每条配方带一个 `status`：

| 状态 | 含义 |
|---|---|
| `verified` | 已实测，有样图可看 |
| `candidate` | 机制推演过，未实跑——**还没人看过画出来什么样** |
| `blocked` | 骨架未写或已判定做不出；选它等于选默认，**不许假装它是新风格** |
| `baseline` | 对照组 |
| `pending` | 进了目录但删词与骨架还没填 |

这套状态是给自己看的。一个配方没跑过就摆出去，等于把不确定性转嫁给使用者。

### 三、负向词的实际地位（一条被实测推翻的直觉）

默认线走 `cfg = 1.0`，采样时负向那一支被乘 0——**负向串当前完全不起作用，正向骨架才是唯一杠杆**。

实测（同 seed，厚涂）：

- A 骨架 + 全负向串 vs B 骨架 + 删词后 → 逐像素平均差 **0.00**
- A 骨架 vs C 无骨架 → 平均差 **55.58**、最大差 **242**

所以 `dropNeg` 字段保留但仅作文档，将来若抬 `cfg` 让负向真生效（B 路）再用。复现脚本：`_studio_preview/probe_ab_negative.mjs`。

## 适配别人的机器

前面的版本只认自己那台 ComfyUI。现在新增了判定内核 `lib/adapt.mjs`：别人装同一个 App，它能自己探明白对方装了哪些模型、该走哪条线。

流程：

```
宿主 /object_info
   → ① 枚举口普查（把每个节点的每个枚举输入摊成一张表）
   → ② 口级分类（按「这个口装的是什么」分，不按值分）
   → ③ 可达反查（同一文件多路可达时选核心加载节点）
   → ④ 机器指纹
   → ⑤ 判线 R0–R7，兜底 B1–B5
   → LinePlan
```

三条不越的线：

1. **判据抄 ComfyUI 自己的**（`model_detection.py` / `supported_models.py`），不自己编"文件名特征表"。
2. **架构语义查不出来就留空**，不套现成模板。
3. **可达路径可自动，架构语义交模板 + 试跑 + 用户。**

其中「口级不是值级」这条是关键：判断依据是"这个输入口在装权重文件"还是"在装一张图片"，不是"这个字符串长得像不像模型名"。按值判会在第三方节点上频繁误判。

离线测试 27/27 与 52/52 全过。

## 目录

| 路径 | 作用 |
|---|---|
| `index.js` | App 入口 |
| `manifest.json` | 清单：能力声明、网络白名单（仅 127.0.0.1 / localhost） |
| `lib/adapt.mjs` | 判定内核：枚举口普查 → 分类 → 可达反查 → 指纹 → 判线 → 兜底 |
| `lib/graph.mjs` | 节点图拼装（`buildGraph` 默认线 / `buildGraphForPlan` 按线拼图） |
| `lib/styles.mjs` | 风格配方表（管线侧唯一权威） |
| `lib/routes.mjs` | HTTP 路由：`/env`、`/submit`、`/run`、`/cancel`、`/rerun`、`/result` |
| `lib/jobs.mjs` | 账本：任务记录、实际出图尺寸（读 PNG IHDR） |
| `lib/comfy.mjs` | ComfyUI 客户端 |
| `lib/custom.mjs` | 自建配方 |
| `lib/review.mjs` | 配方过审 |
| `ui/panel.html` | 界面（单文件） |
| `assets/styles/` | 61 张样图 |
| `风格预设.md` | 配方机制说明 |
| `参考_管线手册.md` | 管线参考 |

---

## 能力与边界

- **网络**：只允许 `127.0.0.1` / `localhost`，不连任何外部服务。
- **模型**：不提供模型，也不下载模型。你的模型在你自己的 ComfyUI 里。
- **不合并图**：只做判定、提交、取回，不处理像素。
